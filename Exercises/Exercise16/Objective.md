## Dummy Data Generator
A Dummy Data Generator using express.js and mongoose.

### Task
* Generate a dummy data in this format in a collection called employees in a db called company
```bash
{
    name: "Harry",
    salary: 45000000,
    language: "Python",
    city: "New York",
    isManager: true
}
```

* **Generate:** 10 such records when a button called generate data is clicked!
* **Express App:** Create an Express app with mongoose to acheive it
* **Clear Collection:** Everytime the button is clicked, you should clear the collection
